# PC-Airflow-Sim

> 纯前端 PC 机箱风道流体与散热热力场实时可视化模拟器（HTML5 Canvas · 单文件零依赖）

直观模拟中塔 ATX 机箱内部在不同风扇布局与硬件负载下的**气流轨迹、热力场分布、正负压防尘状态与核心温控曲线**。打开单个 `index.html` 即可在浏览器中直接运行，也支持零配置部署到 GitHub Pages。

## 核心特性

- **6 槽位风扇自由交互**：覆盖前部 ×3、顶部 ×2、后部 ×1 六个 120mm 风扇槽位，**直接点击画布中的任意风扇**即可在 `进风 (IN)` / `排风 (OUT)` / `停转 (OFF)` 之间实时切换。
- **实时粒子流场与热浮力模拟**：560+ 空气粒子随进风射流、排风负压汇流以及热空气自然上升效应动态流动，经过 CPU 散热塔与 GPU 时吸收热量并由冰蓝渐变至橙红色；负压状态下还可直观看到缝隙处吸入未过滤灰尘微粒的示意效果。
- **核心热力学与声学遥测**：
  - CPU 封装温度 & GPU 核心温度实时数值与过热预警提示
  - 滚动刷新双通道温度走势图
  - 总进风量 / 总排风量（CFM）、机箱内温、正压/均衡/负压评估与风扇噪音估算（dBA）
- **一键风道与负载预设**：
  - 风道预设：`经典微正压`、`满载强穿透`、`负压抽风式`、`闷罐无进风`
  - 负载场景：`待机桌面`、`3A 游戏`、`双烤极限`，同时支持手动微调 CPU TDP、GPU TGP、全局风扇 PWM 转速与室温。
- **单文件零依赖**：无任何第三方库与构建步骤，纯原生 HTML + CSS + JavaScript。

## 快速运行

1. 下载本仓库中的 [`index.html`](./index.html)，直接用任意现代浏览器双击打开即可运行。
2. 或在仓库设置中开启 **GitHub Pages**（Source 选择 `main` 分支根目录），即可在线访问体验。

## 视图选项

画布顶部工具栏支持随时切换：
- **热力场**：开启/关闭 CPU 与 GPU 周边动态热辐射光晕
- **流线尾迹**：在粒子流线模式与离散微粒模式间切换
- **风向箭头**：显示/隐藏各风扇槽位当前进排风方向矢量
- **暂停 / 继续**：冻结当前流场状态便于对比观察

## 说明

本工具采用面向可视化与教学演示的简化热力学和二维流体矢量场模型，用于直观理解正负压风道、风道短路与积热规律，并非工业级 CFD 仿真。
